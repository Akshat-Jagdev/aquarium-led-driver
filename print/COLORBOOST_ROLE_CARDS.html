GOLDEN RULES — apply to every role, every day
1. Never spend money, place orders, or send messages/emails without Akshat's written OK in chat. 2. Never edit files outside the folder your task names. Never touch hardware/ designs, schematics, or firmware. 3. Never post anything publicly. 4. "Draft" means it stays a file for Akshat to review. 5. Report bad news immediately — same day. 6. Confused, broken, or not in your card → STOP and report. Do not improvise.

Role 1 — Procurement & Logistics Runner

Mission: get the right parts, on time, at list price, tracked.
You own: bom/ORDER_TRACKER.md — one row per item: part, vendor, order ID, date, ETA, cost, status (to-order / ordered / in-transit / received / short / LATE).

Tasks

  • T1.1 Place order (supervised) — Akshat gives vendor + cart. You create account, fill address, stop at payment page, hand over. After payment: record order ID + ETA.
  • T1.2 Track shipments — check in-transit rows 2×/week. Past ETA by 3 days → mark LATE + draft vendor email (don't send).
  • T1.3 Receive parts — check vs PARTS_LIST quantities. Missing/wrong/damaged → SHORT + photograph. Correct → RECEIVED.
  • T1.4 Weekly stock snapshot — tracker updated so to-order / ordered / received counts are visible at a glance.

Stop and escalate when

  • Any price changed vs PARTS_LIST
  • Any item unavailable / discontinued
  • Anything needs payment

Role 3 — Bench Technician

Mission: physical build + measurement, following written procedures. Powered tests only WITH Akshat present.
You own: hardware/test/TP-XX_log.md entries, component sorting.

Tasks

  • T3.1 Sort & label parts — per-board kits per PARTS_LIST; report shortages to Procurement.
  • T3.2 Snap panel — boards snap at mouse-bite tabs; file edges smooth; visual check for exposed copper near holes → photograph anything suspicious.
  • T3.3 Assembly — follow docs/assembly_guide.md exactly. LM2596 module (U10): Akshat presets pot to 12.0 V first — never install an unset module.
  • T3.4 Measurements — Akshat powers on; you call out every number from the TP sheet.
  • T3.5 Log same day — date, board ID, raw numbers into TP log.

Never

  • Power a board alone · change a component value · rework a joint without logging it
  • Smell / heat / smoke → power off FIRST, then report
  • Any measurement >10% off the test sheet → stop
