aquarium v0 — PCB Assembly Pack

Component placement diagrams for the 4-board 24 V LED driver panel (fab rev Sep 2026)

Boards (snap apart from panel first)

  1. Board 1 — 150.5 × 20 mm — input: 24V IN → fuse → switch, ESP32 header
  2. Board 2 — 149.0 × 20 mm — RED + BLUE channels
  3. Board 3 — 97.9 × 20 mm — W3 channel
  4. Board 4 — 175.1 × 20 mm — DEEP-RED + W4 channels

Before you solder

  • All components go on the front (the side with the white "AQUARIUM V0 DRIVER" text).
  • Each page's table lists parts in soldering order: resistors → diodes → ICs → capacitors → inductors → fuse → connectors last.
  • Polarity parts: SS310 diodes (K bar), LEDs (dashed box — check datasheet notch), AL8860 (pin-1 dot), electrolytics. Everything else is orientation-free.
  • Work one table row at a time; tick refs off as you go.
  • After each board: continuity-check fuse → switch → driver inputs before LEDs.

How to read the diagrams

  • Coloured box = component body location; label above = reference, below = value.
  • ● dot = pin 1.  K + bar = diode cathode.  Dashed box = LED.
  • Grey artwork = the actual copper / silkscreen of the board (true geometry, exported from the fabbed layout).

Print

  • A4 landscape, 100% scale — but diagrams are enlarged views, only the board outline check needs true scale (use the existing print pack for that).
  • One board per page, 5 pages total.
